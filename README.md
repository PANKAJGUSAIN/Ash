# Ash

A keyboard-first project management platform for fast-moving engineering teams.

---

# Product Philosophy

Ash is designed around speed, focus, and minimal friction.

Core principles:
- Fast interactions
- Keyboard-first workflows
- Minimal context switching
- Lightweight but powerful
- Accessibility-first
- Workflow-focused UI
- Production-grade frontend architecture

---

# Target Users

Small-to-mid engineering and product teams.

Including:
- Developers
- Designers
- Product Managers
- Startup Teams

Built for people who:
- Manage tasks daily
- Need fast workflows
- Switch context constantly
- Prefer keyboard-driven productivity
- Want minimal UI clutter
